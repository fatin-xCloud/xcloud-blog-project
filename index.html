Ship a post in five moves

No dashboard. No plugin spinner. Just one file, one command per stage, and a live URL when you merge.

WordPress dashboard
→
$ npm run blog:*
1

Start the post

Scaffolds the file, frontmatter and all. Replaces "Add New Post."

npm run blog:new -- "Post Title" --category Guide
⚠ never rename the slug after publish
2

Write with Claude Code

Ask it to draft, fill the frontmatter, and tune SEO. Then you just review the diff.

"Draft the post, ~1200 words, 4 FAQs, then run blog:seo and fix anything under 90."
✓ prefer this over writing markdown by hand
3

Set the featured image

One image becomes the thumbnail, social card, and hero. Then compress it.

npm run gen-blog-webp
⚠ raw PNGs run ~1MB — always webp it down to ~40KB
4

Score the SEO

The Rank Math replacement. Scores 0 to 100 and names the exact fix.

npm run blog:seo -- your-post-slug
✓ aim for 80+ before publishing
5

Preview and merge

Check it locally, flip draft off and open the PR. The archive updates itself.

npm run dev → localhost:4321/blog/
✓ merge = live, no sitemap edits needed

Frontmatter at a glance

Every field the file needs, nothing more.

title
≤60 chars, keep "- xCloud"
slug
the URL. locked once live
ogImage
thumb + social + hero
focusKeyword
unlocks SEO checks
faqs
rich result in search
draft
true hides from archive
